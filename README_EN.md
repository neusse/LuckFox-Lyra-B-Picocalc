## Available documents

### Installing Ubuntu 24.04.2 on PicoCalc using Luckfox Lyra B

Step-by-step guide to install the community image `ubuntu-24.04.2-picocalc` on a PicoCalc using a Luckfox Lyra B and a microSD card as the main storage device.

It includes image preparation, use of `upgrade_tool`, entering `Maskrom` / `Loader` mode, selecting the correct storage device, flashing the image, and physically mounting the board inside the PicoCalc.

* [Spanish version](https://github.com/VintaBytes/LuckFox-Lyra-B-Picocalc/blob/main/Linux_Install_LuckFox_Lyra_B/readme.md)
* [English version](https://github.com/VintaBytes/LuckFox-Lyra-B-Picocalc/blob/main/Linux_Install_LuckFox_Lyra_B/readme_en.md)
